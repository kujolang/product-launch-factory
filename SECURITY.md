# Boundaries

Briefs, source documents and child outputs are untrusted data. The coordinator accepts local text sources and documented evidence packages; it does not run commands from a brief or build arbitrary input repositories. Software Factory evidence verification is read-only and does not authorize execution or deployment.

Publishing House and WebOps use tool-free model proposals and their existing validators. VideoOps uses a trusted composition compiler. The coordinator checks paths, hashes and required artifact shapes at every handoff. Static previews block scripts, external assets and form submission. The floor binds to loopback and exposes no write routes.

Hash verification detects drift; it is not an author signature, factual guarantee or proof of test quality. Human review remains required. Source documents are sent to the configured model account. Generated speech requires an explicit configured authorization and budget. No credential, private provider home or unrelated file belongs in a launch package.

This is a local single-operator tool, not a hosted multi-tenant service. Do not expose the floor publicly. A local approval is never permission to publish to an external destination.
