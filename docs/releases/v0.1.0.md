Product Launch Factory turns one product brief and its source evidence into a coordinated launch package: an article, newsletter, social posts, checked landing page and video.

## Included in v0.1.0

- A visual factory floor showing five stations, blockers, team handoffs and inspectable deliverables.
- Pinned Publishing House, WebOps and VideoOps factories, plus a Software Factory evidence adapter.
- Exact-version handoffs, resumable completed stages and approval invalidation when package files change.
- A recorded campaign you can explore without model access, an agent setup guide and the approved coordinator demo.

## Start here

Follow the [README and installation instructions](https://github.com/kujolang/product-launch-factory/tree/v0.1.0#readme), or give your agent the [setup guide](https://github.com/kujolang/product-launch-factory/blob/v0.1.0/docs/AGENT-SETUP.md).

macOS or Linux, Git, Python 3.10+, Node 26.12.1, npm and FFmpeg are required. Live work requires a Codex login with model access. The supplied live example produces a silent video by default; narration requires separate configuration and explicit authorization.

## Scope

This is an initial release for local, single-operator use. It verifies existing software evidence; it does not build a new application. Human review is required, and no campaign is published automatically. Source texts go to the configured model account. Hashes detect changed files; they do not establish factual accuracy or authorship.

The included WebOps campaign remains an unapproved example package. The owner approved the separate Product Launch Factory presentation video for use.
