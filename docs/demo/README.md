# Product Launch Factory demonstration

The front-page video shows the Product Launch Factory coordinator. The retained WebOps campaign is its example workload, not the subject of the film.

Every product shot is an actual coordinator screen: the five stations and finished package, Publishing House's article, the checked landing page inside the coordinator, and the verified team handoffs. The opening stays on the floor instead of showing a title card. Narration explains the benefit of keeping teams on the same source evidence, seeing blockers and reviewing the complete launch before publication.

The floor now presents a launch package with five inspectable deliverables. Handoffs show the receiving team and retained file count, with exact hashes available on demand. These views use existing run artifacts; they do not simulate execution or change the approved state. [Browser checks](floor-verification.json) cover each output button, all five handoffs, exact-version disclosure and the mobile layout.

The earlier WebOps campaign clip and sealed evidence remain under `docs/example-run`. This presentation revision does not alter that package or turn technical review into human approval.
